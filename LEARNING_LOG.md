# Learning Log

## Environment Setup

I installed Git, Python 3, and Docker on my system. The main challenge was ensuring all tools were properly added to my PATH and accessible from the command line. I verified each installation by checking the version numbers.

## Git Skills Learned

- `git init` - Initialize a new repository
- `git clone` - Clone an existing repository
- `git add` - Stage changes for commit
- `git commit` - Create a commit with staged changes
- `git push` - Push commits to a remote repository
- `git pull` - Pull changes from a remote repository
- `git checkout` - Switch between branches
- `git branch` - List or create branches
- `git merge` - Merge branches together
- `git log` - View commit history
- `git status` - Check repository status

## Linux Commands Learned

- `mkdir -p` - Create nested directories
- `touch` - Create empty files
- `echo` - Print text or write to files
- `cat` - Display file contents
- `cp` - Copy files
- `mv` - Move or rename files
- `rm` - Remove files
- `ls -la` - List files with details
- `pwd` - Print working directory
- `whoami` - Display current user
- `uname` - Display system information

## Python Skills

- Defining functions with parameters and return values
- Handling edge cases (like division by zero)
- Importing modules and packages
- Creating Python packages with `__init__.py`
- Using the `platform` and `os` modules for system information
- Building interactive command-line applications
- Input validation and error handling
- String formatting with f-strings

## Docker Knowledge

I learned that Docker containers are lightweight, isolated environments for running applications. Images are templates used to create containers. Key concepts include:

- Running containers with `docker run`
- Port mapping to expose container services
- Detached mode for background processes
- Container lifecycle management (start, stop, remove)
- The difference between images and containers

## Challenges Faced

The main challenge was understanding how Python packages work with `__init__.py` files. I initially had import errors when trying to run my test script. I resolved this by understanding the difference between running scripts from different directories and how Python's module system works.

Another challenge was remembering all the Docker flags and their purposes. Creating the DOCKER_NOTES.md file helped solidify my understanding.
